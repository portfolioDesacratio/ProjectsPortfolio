# парсер новостей с lenta.ru 📰

собирает заголовки новостей и сохраняет в excel или csv

## как запустить

```bash
pip install -r requirements.txt
python parser.py
```

потом введешь сколько страниц парсить и в каком формате сохранить

## фичи
- собирает заголовки + ссылки + время + категорию
- сам удаляет дубликаты
- можно сохранить в xlsx или csv
