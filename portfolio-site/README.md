# сайт-портфолио 🌐

моя личная страница с проектами

## как открыть

просто открой `index.html` в браузере

или запусти сервер:
```bash
python -m http.server 8080
# потом зайди на http://localhost:8080
```

## что внутри
- html + css + js (без всяких реактов и прочего)
- темная тема
- работает на телефонах
- анимации
