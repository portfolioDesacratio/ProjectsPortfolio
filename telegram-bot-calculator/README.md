# тг бот калькулятор 🤖

простой калькулятор в телеграме с кнопками

## как запустить

1. иди к @BotFather в телеге, создай бота, получи токен
2. скопируй `.env.example` в `.env` и вставь туда свой токен
3. установи библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
4. запусти:
   ```bash
   python bot.py
   ```

## команды
- `/start` — запустить калькулятор
- можно писать примеры текстом или тыкать кнопки

## что внутри
- питон + aiogram 3
- безопасное вычисление (не даст взломать себя)
